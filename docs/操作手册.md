# 操作手册

## 1. 编译并运行

先确认已安装 C 编译器和 Make，然后在项目根目录执行：

```sh
make run
```

程序会先构造一段 HTTP 请求报文，再从 Ethernet 层开始解析同一组字节。每一层的日志按 `[L2]`、`[L3]`、`[L4]` 和 `[APP]` 标识。

## 2. 观察日志

重点看以下内容：

1. `[L2 Ethernet]`：目的/源 MAC 以及 EtherType。`0x0800` 表示后续是 IPv4。
2. `[L3 IPv4]`：源/目的 IP、TTL、总长度和协议号。`6` 表示后续是 TCP。
3. `[L4 TCP]`：源/目的端口、Seq、Ack、窗口和控制标志。`PSH ACK` 表示携带数据并确认对端字节流。
4. `[APP]`：TCP 载荷的 HTTP 请求。日志把回车和换行显示为 `\r`、`\n`，方便看出 HTTP 行边界。
5. `[DONE]`：解析正常结束。这里模拟的是内存中的报文，不会连接到示例 IP 地址。

## 3. 重新构建与清理

修改 `src/main.c` 后再次运行 `make run`。删除编译产物：

```sh
make clean
```

随后 `make run` 会重新编译。

## 4. 推荐练习

- 修改 `http_request` 内容，观察 TCP 载荷字节数和 IPv4 总长度如何变化。
- 修改源端口或目的端口，观察 TCP 层日志。
- 将 TCP Flags 从 `PSH|ACK` 改为只带 `ACK`，观察标志解析。注意无载荷时仍可有 ACK。
- 临时修改 EtherType、IPv4 Protocol 或报文长度，观察解析器在哪一层拒绝报文。
- 修改 IP 地址后重新运行，观察 IPv4 校验和和 TCP 伪首部校验和会随之重算。

## 5. 常见问题

- **找不到 `make`**：安装 Xcode Command Line Tools（macOS）或系统的 GNU Make 软件包。
- **找不到 C 编译器**：确认 `cc --version` 可运行；macOS 可安装 Xcode Command Line Tools。
- **想抓取真实网络流量**：当前程序不调用抓包 API。先用 Wireshark观察真实报文，再对照本程序的字段布局；真实抓包涉及系统权限和网卡数据，与本地内存模拟是不同练习。
