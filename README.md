# C 网络报文学习框架

这个 C11 示例让两个终端里的进程在本机交换自构造的 Ethernet/IPv4/TCP 教学帧。程序模拟 TCP 三次握手、双向数据确认、空闲超时和四次挥手，并在发送端和接收端分别打印逐层封装/解包日志。

底层只用 UDP loopback 传送整帧字节；TCP 头、IP 头和状态机都由示例程序构造与解析，不需要管理员权限，也不会连接外部主机。它用于理解协议字段和状态变化，不是操作系统内核 TCP 的抓包工具。

## 两个终端运行

先在项目目录运行 `make`。终端 A 启动接收端：

```sh
./build/packet_demo receive 9000 5
```

终端 B 启动发送端：

```sh
./build/packet_demo send 127.0.0.1 9000 5 "你好，接收方"
```

最后一个数字是接收端在回复并收到确认后等待的空闲秒数。超时后接收端发起 FIN，双方打印四次挥手。更完整的步骤见[操作手册](docs/操作手册.md)。

`make run` 显示命令帮助；`make clean` 清理编译产物。
